# Changelog

## 0.2.0

Initial repository packaging of the batch-capable Phonic Drive Analyzer v2.

- Multiple file/directory/glob/file-list inputs
- Batch JSON/CSV outputs
- Optional `song_lens` annotations
- Per-frame stereo width and correlation
- Multi-feature transition speed and acceleration
- 3D state-space export coordinates
- Spectral checks for declared resonance anchors
- Per-track and batch visualizations
